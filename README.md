# BerOpp Markt

A responsive, multilingual (Deutsch / English / Français) static product-discovery demo.

## Run locally
Open `index.html` in a browser.

## Deploy
Connect this repository to a static hosting provider such as Netlify. No build command is required; publish directory is the repository root.

## Demo scope
This version uses illustrative sample product cards and does not contain live prices, purchasing, affiliate tracking, or Amazon product links. Any future commercial affiliate features must be reviewed and managed by an authorized adult account holder and must follow the applicable program policies and disclosure requirements.
